# Support

Use GitHub issues for reproducible SYBuilder defects, documentation gaps and adapter contract problems.

Include:

- SYBuilder commit or release version;
- operating system, Python, Node and Git versions;
- selected stage and `documentPlatform`;
- exact exit status (`PASS`, `FAIL`, `UNABLE`, or stage-specific equivalent);
- sanitized logs and a minimal reproduction.

Do not attach OAuth tokens, tenant URLs, private documents, real user screenshots, credentials or proprietary
product data. Security reports should follow [`SECURITY.md`](SECURITY.md), not a public issue.

External platform outages, account permissions and vendor authentication are outside SYBuilder's control,
but adapter misclassification—for example reporting success without native readback—is a SYBuilder defect.
