# S2 / S4：细致报告写作循环

基于用户更新后的 `968b674` 实施。用户要求在现有版本落实颗粒度改进；随后明确只保留 `main`。本地临时分支已经删除，其提交均保留在 main，远端检查只有 main。本次不修改 PRD 章节结构、不删除调研内容、不将技术调研强制改成 GUI 遍历。

## 原因与改动

- 目录、数量和填表检查不能保证正文足以指导下游。增加共享写作循环：发现分母回查 → 完整域样章 → 独立消费检查 → 逐域批次 → 逐级对比 → 决策 → 垂直 PRD 切片 → 保细节组装及平台验收。
- 正式纳入范围的功能均需最低行为说明，优先级只影响额外实验深度；候选池的清单级记录不冒充正式单品详解。
- 颗粒度取决于独立行为，不要求固定四层，不把每个点击算成新功能。已有账本及 state.md 继续是进度与事实源，不增加平行正本。
- 保留 tech-approach 新模式，按源码中的策略决策点说明输入、分支、结果和代价；读代码不等于运行验证。共同的是样章、消费检查和同版发布。
- 增加本地教学应用、真实截图功能域样章、研究到 PRD 切片。样例不是商业竞品研究，也不是云平台交付。复现复用已有 CDP 模块，只操作隔离的本地页面。
- 最新基线的 script-count 原写 98、实际 99，纠正文档计数；不重置无损基线或降低检查条件。
- 全量自测发现两个既有变异靶随新版失效：图源门禁数量已不是 45；intent 模板已被技术调研参考再次引用。前者改为把实际数量加一，后者在临时副本删除全部入口，保留 no-op 检查和生产判据；补回归证明剩余任一入口仍应通过、全失才失败。

## 协作范围

用户本轮直接指派在最新版修改。PRD 模板仅追加共享写作入口，保留其 Claude 所有权；tech-approach 两份原归 Claude 的文档登记共享本轮写作/安全回读补充，既有归属不转移。新增指导和示例登记给 Codex。主入口、阶段参考、模板、状态表、计数与验证记录按既有 shared 契约修改。

承重共享文件逐项说明：`skills/product-flow/SKILL.md` 只接入写作指导并修正技术研究与 GUI 分流；`skills/product-flow/references/design-quality-gates.md` 只校正 98→99 的既有计数遗漏；`skills/product-flow/references/path-ownership.json` 声明新资产及本次共享范围，不转移原所有权；`skills/product-flow/references/no-loss-renames.md` 登记“清单级”的收紧说明及理由，不重置无损基线。`scripts/test-remediation-contracts.py` 增加样章证据完整性与禁止覆盖既有证据的回归，不把这些测试说成写作质量评分。

其余共享写作入口：`skills/product-flow/references/s2-tech-approach-runbook.md` 增加策略样章与安全增量写入，不变更源码判据；`skills/product-flow/templates/tech-research-report.md` 接入同一指导；`skills/product-flow/references/s3-s4-product.md` 和 `skills/product-flow/templates/prd-complete.md` 只补事实到产品决定及逐功能写作入口；`skills/product-flow/templates/research-report.md` 补详解先于比较与摘要的执行顺序；`skills/product-flow/templates/state.md` 增加写作续跑引用，不复制事实正本。

## 验证边界

`skills/product-flow/scripts/consistency-gate.py` 只修上述两个测试靶，生产判据保持不变；`skills/product-flow/references/.selftest-measured.json` 仅由真实完整自测重新生成，不手填成功结果。

在后续验收记录中分别记录真实浏览器样例、结构/回归检查和独立写作实验的实际结果。它们不等于 Claude 已稳定生成真实竞品长报告，也不等于飞书或钉钉已回读验收；未跑项目不得写通过。本轮不降低现有 RELEASE_BLOCKERS 的边界。

验收经过：第一轮暴露两个失效变异靶；修复后第二轮零失败，但旧测量摘要导致相关变异未验成；由真实运行刷新摘要后，第三轮全量无失败、无跳过。没有把第二轮的 UNABLE 折成通过，也没有手工改成功标志。最终仅补此验收说明及根目录发布边界，不再改动被测代码/模板。
