# 离线图文样章与回归夹具

`demo.html` 是无账号、无网络的本地教学应用。`capture-demo.cjs` 用隔离 Chrome 真实点击空输入和创建任务，生成 `shot.png`。截图中的文字、交互和账号范围均为公开测试数据。`report.md` 说明已测、未测与下游决策，不代表任何商业竞品能力。

`readback.xml` 是保存完整正文和模拟图片实体的离线协议夹具，不是平台 API 返回；本目录不能签发 live 回执。`run-golden.py` 验证单品正文/遍历/回读检查可同时满足，并破坏索引、状态、事件、媒体，要求指定检查返回 FAIL；UNABLE 不算捕获成功。

重拍图需本地 Chrome；不会使用已有浏览器 profile、账户或外网。完整产品研究还需对全部叶子功能的实测截图、状态/恢复、横比和原生云文档做独立审核，本样章不替代这些验收。
