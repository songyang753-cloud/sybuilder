# 原型工作流与输入适配

本页承接原演示工程能力；产品骨架唯一来源是 `../../templates/proto/`，不引入第二套
base.html。读本页后再按 `../../references/s5-s6-design.md` 完成 S6。
只做演示，不宣称具有真实后端、生产数据或可上线能力。

## 输入与确认

| 输入 | 必做 | 边界 |
|---|---|---|
| PRD | 功能/分支逐条对应路由与状态，回标章节、F/AC ID；共享页面可承接多个功能 | 本期不做的不混入演示；冲突先裁决，不猜 |
| 一句话需求 | 补齐观众、要证明的价值、目标端、视觉依据，形成场景清单 | 未提供设计稿就明确写“口述依据”，不伪装为设计还原 |
| Figma | 只读取原稿；逐板取上下文，实测间距、字重、字号、行高、颜色、圆角 | 不改原稿；素材原样提取后优化，不擅自重绘；补充交互逐项披露 |
| 现有原型 | 先读 tokens、路由、store 与事件绑定；先做可恢复备份再局部修改 | 保留既有结构与实测修正，重写骨架须获授权；变更后重验导航与受影响场景 |

场景清单至少包含“路由/状态、产品 UI 触发路径、依据、正常结果、失败与恢复”。
先确认清单再写 HTML；已确认的 rich brief 不重复提问。无依据的补充作为提案，不暗中加功能。

## 实现顺序与可达性

1. 先让所有路由、导航、返回、状态共享跑通，再填内容，最后叠视觉皮。
2. 路由是页面，空/加载/错误/无权限是数据与接口驱动的状态；不能各画一屏静态幻灯片。
3. 状态由 store 持有，不从 DOM 反推；路由切换走唯一入口；动态视图重渲染后事件仍有效。
4. 主流程必须从产品 UI 发起，输入可编辑、回车有响应、按钮有可观察结果、跨页返回状态仍在。
5. 评审壳只辅助注入故障，不进入产品键盘顺序和截图；不能靠改 URL 或外挂控制条完成主交互。
6. 每页有来路与去路，弹层支持合适的遮罩/Esc 关闭及焦点回收；关键流程不能卡死。
7. 首屏使观众知道从哪开始；未覆盖但确有依据的入口 disabled 并解释，不留死链。
8. Toast 统一实现，清除旧计时器；长错误就地呈现，避免 alert 打断。hover 不能是唯一入口。
9. 场景数量依据故事线确定。超过约 12 个页面可按主线拆分，但不能拆断单条任务闭环。

## 视觉与尺寸

- 使用同一份 DESIGN.md/tokens；最低包括主色各交互态、文字层级、填充/描边、语义色、间距、圆角和阴影。不能在组件中另建一套值。
- 中文字体须有跨平台本地后备。离线单文件不依赖 Google Fonts/CDN；外部视觉建议不得破坏交付约束，冲突记录理由。
- 图标内联 SVG；位图压到实际显示尺寸并内联，单图建议不超过 200 KB、整件建议不超过 5 MB；超过则解释清晰度与大小取舍。
- 桌面/手机/平板外框按目标端选，不机械套固定尺寸。单端保持导航可见；多端依据 `platform-parity.md` 分开设计。
- 响应式断点按导航宽、间距、内容宽、两侧 padding 求和；窄屏改成可达的顶部导航，不直接隐藏导航。
- 核对内容宽度与空白：少列表不把内容撑到两边；适量样例数据说明样例身份；不能为填空造不存在的功能或统计。
- 实测边距、字体和行高。检查半像素描边挤压内容盒、不同平台滚动条占宽；修法服从可访问性与实际测量，不一律隐藏滚动条。
- 深浅色与字体气质按需求/品味档案，不擅自加模式；模式复用令牌名，不复制组件样式。

## 验证与交付

1. 用 `scripts/bundle.mjs` 从四层目录骨架生成单文件，CSS/JS/位图/所需字体全部自包含。
2. 自测注入临时副本，交付件不得残留断言代码；测几何前关过渡和动画。
3. 至少宽/中/窄三视口（可用 1600、1280、820 宽，移动端另验实际断点）。断言包括：
   零外链、路由目标存在、每场景非空、起手场景正确、无横向溢出、关键几何符合设计。
4. `selftest.mjs` 与 bundle 都为 0=通过、1=产物不合格、3=没能测。零断言不能算通过，
   丢素材也是产物缺陷，不能只看没有 http 链接。脚本输出不替代 GUI 走查。
5. 几何失败先定位隐藏场景/选择器是否正确，再核动画、滚动条、描边；不删除失败断言来求绿。
6. 最后一次编辑后逐屏截图、逐条主线 GUI 实走；断言全绿也可能布局难看或像半成品。
   若 file 协议不可访问，可用绑定 127.0.0.1 的本地静态服务；先用对照区分工具噪声与产品错误。
7. 交付单文件、进入方式和主线；整页依据缺失标“结构性占位”，局部补文案/图标逐项披露，
   数据明确为样例。原型中的诚实占位不允许被当成竞品研究的真实截图或原生交付证据。

生成源目录和单文件是同一份逻辑的两种形态，不得分开手工维护。
