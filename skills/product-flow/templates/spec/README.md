# `templates/spec/` — S5.2 的机器可读产出（sidecar 契约组）

**这些 sidecar 不是「文档的附件」，它们是交给研发的物料本身。**
> ⚠️ 数量以目录实际文件为准（`ls *.json`），本文不手填数字——
> 手填的数量在新增文件那天就变成谎言（实测：写「六份」时实际已有 8 份）。

`interaction-spec.md` 是给人读的；这批 sidecar 是给机器读的（**数量以目录为准，不手填**——见上）。
两者不是重复：md 里那些**会被复述、会漂移**的东西（文案、字段规则、状态清单、
关键路径、元素名、接口形状）在这里以**引用得到、对得上账**的形式存在一次。

> 📌 本 SOP 记过「md→md 三种衰减：丢项 / 改写漂移 / 静默降级」。
> 最隐蔽的是第三种：`P95 ≤ 300ms` 被复述成「响应要快」—— 读起来完全通顺，而约束没了。
> **引用 ID 不会漂，复述文本会。** 这批 sidecar 就是把「会漂的东西」搬出散文。

| 文件 | 内容 | 谁在吃 |
|---|---|---|
| `operations.json` | 调用面：方法 / 入参 / 返回 / 错误码 | demo 的 `20-api.js` · **研发的接口实现** · `spec-sync-gate` |
| `copy.json` | 全部文案 + 控件字数上限 | demo 的 `60-copy.js`（**生成，不手写**）· 上限自动核 |
| `validators.json` | 字段校验规则（声明式，不是代码） | demo 的 `70-validators.js`（生成）· **研发的表单校验** · S8 输入类用例 |
| `elements.json` | 元素身份 = **role + 可访问名称** | demo · **S8 用例选择器** · Figma 图层名 · 无障碍验收 |
| `states.json` | 每个界面适用哪些状态 + **每个状态由哪个 `scn` 触发** | `scenario-matrix-gate` · S8 状态类用例 |
| `flows.json` | 关键路径：步骤 + 每步的 role/name + 终点断言 | `flow-walk-gate` · **S8 用例直接生成** |

## 两条硬纪律

1. **`copy.json` / `validators.json` 是源，`js/60-copy.js` / `js/70-validators.js` 是产物。**
   用 `scripts/spec-to-js.py` 生成，**不许手改产物**。
   `spec-sync-gate.py --check` 会重新生成一遍并比对 —— 手改过就红。
2. **元素身份用 role + 可访问名称，不用自造 slug。**
   来源是 testing-library / Storybook 的明确建议：「用真人使用界面的方式去找元素，
   `data-testid` 是最后手段」。好处是同一个标识**同时**是无障碍契约、
   测试选择器、研发的语义命名 —— 一处对，四处对；自造 slug 只对一处。


## `end-differences.json` —— 端差异登记表

双端产品专用，喂 `scripts/platform-parity-gate.mjs --declared`。

⛔ **每条必须写 `reason`。** 不写理由的登记只是个静音开关 ——
「刻意的信息分层 / 屏幕放不下砍了 / 做的时候忘了」这三种情况**在产物上长得一模一样**，
理由是唯一能把它们分开的东西。⭐ 一个能一键静音的判据，最终会被用来静音所有东西。

| 字段 | 含义 |
|---|---|
| `texts` | 允许只在一端出现的文本 |
| `anchors` | 允许两端需求锚点不同（功能本就仅在某一端提供时） |
| `reason` | **必填**。为什么这个差异是对的 |


## `elements.json` 的两个出口（都必须写理由）

| 字段 | 什么时候用 | ⛔ 必须同时写 |
|---|---|---|
| `dynamic: true` | 可访问名来自数据（如列表项标题） | `nameFrom`（指向 `operations.json` 的 types 字段） |
| `runtimeSlug: true` | **slug 是运行时拼出来的**（如 `data-el="tab-" + n.path`），静态扫 HTML 找不到 | `slugFrom`（说明它从哪拼出来） |

⛔ **不写来源的豁免就是静音开关** —— 与端差异登记同一条纪律。
⭐ 判据不能因为「静态扫不到」就一律放行（那会让真的漏了也过去），
也不能一律判红（那会惩罚正确实现）。**出口 + 必填理由**是唯一不制造假阳性又不开洞的形状。

📌 2026-09-04 立。起因：补移动端关键路径时用到底部 tab 的 `tab-create`，
它由 `renderTabBar` 按 NAV 表拼出来，静态扫不到 —— 与场景锚点是同一形态。
