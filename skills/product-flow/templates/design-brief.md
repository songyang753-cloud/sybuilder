## ⭐ 动笔前的三件事（缺一不许进 S5.1）

> 这三句是后面**所有**设计决策的裁决依据。填不出来说明还没想清楚，不要往下走。

### 1. Design Read（一句话）
> 我把这个读作：给 **<谁>** 的 **<什么产品>**，**<什么调性>**，倾向 **<什么设计系统>**。

### 2. Memorable-thing（一句话）
> 用户第一次看完这个产品，我要他记住的**唯一一件事**是：**<____>**

⚠️ 之后每个设计决策都要回查这一句。
> Design that tries to be memorable for everything is memorable for nothing.

### 3. 由此产生的核心设计张力（可能没有，有就写）
> <如：照片要当主角 ↔ 自生长能力要可见——界面完全退让，差异化就隐形了>

## ⭐ A 概念锁 · 三个视觉方向登记表（无既定品牌时必填；见 `delivery-pipeline.md` §四）

> ≥3 个**成体系且实质不同**的方向 —— 换色/换圆角/换插图**不算**不同方向。
> 每方向四个差异维度**逐格填**；四格里有任何一格与另一方向相同，就说明只做出了两个方向。
> 有严格品牌系统时可只做一个主方向，但**必须**在下面「品牌豁免」行写明被排除的替代方向与理由。

| 方向 | 构图与阅读路径 | 字形气质与层级 | 色彩/材质/光影 | 关键操作与反馈的视觉表达 |
|---|---|---|---|---|
| 方向 A <名字> | | | | |
| 方向 B <名字> | | | | |
| 方向 C <名字> | | | | |

## ⭐ SAFE / RISK 提案（RISK 是**审慎的突破提案**，不是每项目凑数的配额）

设计自洽只是及格线。**真正的问题是「你在哪里有意识地选择了什么」。**

### SAFE（符合品类惯例，说明为何这里要求稳）
- **SAFE-1** <是什么> —— <为何这里求稳>
- **SAFE-2** <是什么> —— <为何这里求稳>

### RISK 提案（建议 2–3 条；每条四要素缺一不可，**只有被批准的才进入执行**）

> ⚠️ 表头是**列名**，不是内容。四个格子都要真的填，留空即视为未完成。
> 由 `scripts/design-intent-gate.py` 逐行核。⛔ RISK 不自动等于好，也不要求出现在每一屏。

| # | 是什么 | 为何成立 | 得到什么 | **代价是什么** | 批准状态 |
|---|---|---|---|---|---|
| RISK-1 | | | | | 提案 / 批准 / 否决 |
| RISK-2 | | | | | |

⚠️ **RISK 数为 0 合法，但必须写一行**：「本项目为何没有值得评估的突破：<理由>」——
金融合规工具选择零突破可能完全正确；**没写理由的零才是模板货**。
## ⭐ 两轴声明（机读块，**必填**）

> `scripts/taste-memory.py check` 读这一块。**不许从散文里猜**——
> 猜出来的比对既不可复核，也会在措辞一改时静默失效。

```
<!-- taste-axes
品味轴: 明暗=<浅色/深色> | 档位=<克制/标准/丰富/极致> | 字体气质=<衬线/无衬线/等宽/展示体> | 色温=<暖/冷/中性> | 密度=<紧凑/标准/宽松> | 动效=<克制/标准/丰富/极致>
执行轴: 字体族=<具体字体> | 强调色=<具体 hex> | 视觉锚点=<食谱名> | 布局=<构图手法>
-->
```

**偏离品味档案是允许的，沉默地偏离不允许。** 要偏离就在下面写一行：
```
偏离明暗：本次是影院模式，深色是内容要求，不是风格选择
```

⚠️ **跨代要求分两轴，方向相反**（`scripts/taste-memory.py`）：
**品味轴收敛**（与档案强信号一致，偏离要写理由）· **执行轴发散**（Greenfield/Overhaul 不许复用上代具体值）。
⛔ **Preserve 模式下执行轴反过来：必须保持**——要动就走 Overhaul，并说明旧方案哪里错了。
⭐ 判据只有一条：**换掉它，用户会说「这不是我要的方向」，还是「这个也行，甚至更好」？**
前者是品味，后者是执行。**「衬线 vs 无衬线」是品味；「Georgia vs Source Serif」是执行。**
