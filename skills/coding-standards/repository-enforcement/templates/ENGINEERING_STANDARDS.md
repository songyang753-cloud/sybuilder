## 0. 质量门禁（Definition of Done）

一个变更"完成" = 通过 CI 全部**强制门禁**。下表按项目实际填写（强制 / 咨询(棘轮) / 信号）。

| 门禁 | 命令 | 类型 |
|---|---|---|
| <格式> | <gofmt / prettier ...> | 强制 |
| <静态分析> | <staticcheck / eslint ...> | 强制 |
| <测试(含竞态)> | <go test -race / vitest ...> | 强制 |
| <类型> | <tsc / vue-tsc / mypy> | 强制 或 咨询(棘轮) |
| <漏洞扫描> | <govulncheck / npm audit / pip-audit> | 强制 或 咨询 |
| <依赖一致性> | <go mod tidy 无 diff / lockfile> | 强制 |
| <密钥扫描> | gitleaks | 咨询(棘轮) |
| <契约> | <redocly / schema lint> | 强制（如有对外 API） |

**棘轮原则**：新检查存量多先设咨询门禁，清零后转强制，只紧不松。

## 1. 架构原则（固化已有，禁止回退）

> 📐 **推荐默认架构见 [`references/proven-web-architecture.md`](../references/proven-web-architecture.md)**
> ——一套生产验证过的 **API-First 模块化单体**蓝图（分层/横切层/事件总线+队列/数据治理/
> 配置即数据/安全模型/可观测/发布工程/前端 SSR）。新 Web 项目建议直接采用并按栈裁剪。

把项目真实的架构原则写进来（采用蓝图则摘其要点 + 标注本项目的偏离与理由）。核心默认值：

1. **模块化单体**：领域模块 `<domain>` 自带 model+repository+service+handler，对外只暴露 Module()/RegisterRoutes()；跨模块不直接调对方 repository。
2. **解耦走事件**：跨模块副作用经事件总线发布订阅；耗时/可重试副作用经队列异步（独立 worker）。
3. **优雅降级是契约**：任一外部依赖（缓存/邮件/搜索）缺失或故障必须降级而非崩溃。
4. **派生优于反范式**：低基数统计读时派生；高频计数才用反范式列 + 条件更新幂等防负。
5. **配置即数据**：运营可配项存白名单表 + 严格 schema 校验（管理员配置也不免检）。
6. **API 版本化**：对外 `/api/v1`，契约先行，同版本只向后兼容。
7. **进程拓扑**：API 与异步 worker 分进程；运维/对账是独立一次性命令。
