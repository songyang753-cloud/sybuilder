# 反向推导证据链：four-node-review → 编程准则

**方法**：对 four-node-review 的每一条机制问一句——
**「写代码的当下做什么，能让这道审查一条都查不出来？」**

收录判据：只收**能在写这行代码时照着做**的；只能在写完之后检查的不收（那是审查，不是规范）。

**母题**（four-node-review 全文四个病的共同形状）：
> 告诉你「有没有问题」的那个东西，本身可能在说谎。

反向到编程阶段 =
> **你写的每一段「报告自己状态」的代码，都必须是它所声称那件事的真实函数。**
